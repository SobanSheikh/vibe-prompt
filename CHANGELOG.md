# Changelog

All notable changes to Vibe Prompt are documented in this file.

## 0.9.0

- Added local microphone recording and editable rolling transcript previews.
- Added verified whisper.cpp runtime and Whisper model installation.
- Added Linux, Windows, and macOS desktop support for x64 and ARM64.
- Added microphone selection, model switching, download progress, cancellation, and missing-file recovery.
- Added cumulative previews for more coherent partial transcripts while preserving full final transcription.
- Kept audio and transcription local to the machine running the VS Code interface.
